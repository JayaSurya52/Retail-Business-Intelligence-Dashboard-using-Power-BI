# Retail Business Intelligence Dashboard using Power BI

## Overview
This project is a professional multi-page Power BI dashboard developed to analyze retail sales performance, profitability, customer behavior, and shipping efficiency using business intelligence and data visualization techniques.

Worked with approximately 9,900+ retail order records and created 15+ DAX measures to generate actionable business insights.

## 3. Profit Analysis Dashboard

## 4. Customer Analysis Dashboard

- Average Shipping Days

---

# Key Insights
- Technology category generated the highest sales.
- High discounts negatively affected profitability.
- Western region contributed the highest revenue.
- Standard shipping mode was used most frequently.
